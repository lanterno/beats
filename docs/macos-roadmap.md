# LifePete — macOS Roadmap

> LifePete on the Mac is the companion app. This roadmap is the
> Mac-only ambition: the things a desktop with a menu bar, a window
> server, a Focus engine, and a Continuity stack can do that no other
> platform can match.
>
> **Aesthetic:** Brutalist Luxury, applied to the OS. Ambient where the
> system invites it (menu bar, floating chip, Stand By), monastic
> elsewhere (no notification spam, no dock bounce, no chrome).

The work below assumes the cross-platform companion already covers
timer / flow / coach / health. Items here are macOS-native because they
*should* be, not because they were ported.

---

## The work

Every idea that was listed here is an issue in Linear — the
[LifePete project](https://linear.app/elghareeb/project/lifepete-a8ecce3a86de), milestone *macOS* — carrying the design notes
it had here, and the milestone's description holds the order to pull them
in: distribution first (signing, Sparkle, the Cask), Apple Intelligence
last.

Shipped since this was written: the Dock badge, the menu-bar flow
sparkline, the template menu-bar icon and the ⌃⌥T palette hotkey. The ideas
that were cut (the floating now-bar, the Touch Bar, Mac widgets, Stage
Manager layouts) are there too, as canceled issues with the reason, so
they are not proposed again without it.
