# Docs

What is **built**, and why. One file per area, each holding the decisions
behind it, the data model, the HTTP contract and the rules the UI keeps.
[roadmaps/](../roadmaps/) is the other half — what is not built yet.

These are the files code comments cite, by path: a comment describes what the
code does, so it points here. Moving or renaming one means updating those
citations, which is why the files are flat and named for their subject rather
than filed into folders.

Open work is not here. A bug, a follow-up or a question to decide is a
[GitHub issue](https://github.com/lanterno/beats/issues); a "Remaining" or
"Follow-ups" section in one of these files is a mistake to fix, not a section
to maintain.

| File | What it covers |
|------|----------------|
| [work-contracts.md](work-contracts.md) | Day-job contracts: dated terms, regional holidays, absences, the vacation entitlement, the overtime balance and the monthly timesheet |
| [project-page.md](project-page.md) | The project page, the week ledger behind it, and the afternoon and dusk theme |
| [billing.md](billing.md) | Clients a freelancer bills: rates, billable marks, the month's figures, billing budgets, and the report links a client reads with no account |
| [organisations.md](organisations.md) | One account, one timeline, many employers: the four rules, the decisions, the data model, employment and scale |
| [pricing.md](pricing.md) | What an organisation pays, and the market it was priced against |
| [companion-offline.md](companion-offline.md) | The companion's offline queue: what is queued, in what order, and what a replay may and may not do |
| [images/](images/) | The README's screenshot, and the social preview with the command that renders it |

Documents outside this folder, because they are read by people who are not
working in it: [DATA.md](../DATA.md), [PRIVACY.md](../PRIVACY.md),
[ARCHITECTURE.md](../ARCHITECTURE.md), and a README per surface.
